Política de Privacidade

Pequenas Histórias · Última atualização: 17 de novembro de 2026 · English version

Uso dos Serviços de API do YouTube

O aplicativo "Pequenas Histórias Publisher" usa os Serviços de API do YouTube. Ao usá-lo, o usuário concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

1. Quem somos

"Pequenas Histórias" é um projeto pessoal de publicação de contos históricos, mantido por Fábio. O aplicativo "Pequenas Histórias" é uma ferramenta de uso exclusivo do próprio autor para publicar os seus conteúdos nas suas próprias contas de YouTube, Instagram e X. Ele não é oferecido ao público e não tem outros usuários.

2. Quais dados o aplicativo acessa

  • YouTube (Google): informações básicas do canal do autor e permissão para enviar e gerenciar vídeos nesse canal.
  • Instagram (Meta): informações básicas da conta profissional do autor e permissão para publicar conteúdo nela.
  • X: informações básicas da conta do autor e permissão para publicar posts nela.

O aplicativo não acessa dados de outras pessoas, como seguidores, mensagens privadas, contatos ou dados de visualizadores.

3. Como os dados são usados

Os dados e permissões são usados apenas para publicar, agendar e conferir os vídeos e posts do próprio autor. Eles não são vendidos, alugados, compartilhados para publicidade nem usados para treinar modelos de inteligência artificial.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Armazenamento, compartilhamento e exclusão

A autorização de acesso ao YouTube (token OAuth) fica guardada como segredo criptografado no repositório privado do autor no GitHub e só é usada pelo script de publicação. Instagram e X usam o serviço de integração Composio. Nenhum outro terceiro recebe esses dados.

O aplicativo guarda apenas os identificadores e o estado dos vídeos que ele mesmo enviou ao canal do autor. Não há cookies nem coleta de dados de visitantes neste site. Os dados guardados podem ser excluídos a qualquer momento, a pedido, pelo contato abaixo; ao revogar o acesso, o token é excluído em até 7 dias.

5. Como revogar o acesso

O acesso pode ser revogado a qualquer momento nas configurações de cada conta:

  • Google/YouTube: página de configurações de segurança do Google
  • Instagram: Configurações > Apps e sites
  • X: Configurações > Segurança e acesso à conta > Apps e sessões

Após a revogação, os tokens deixam de funcionar e são descartados.

6. Contato

Dúvidas sobre esta política podem ser enviadas por mensagem direta ao perfil @pequenas_historias_ai no Instagram.

Privacy Policy (English)

Last updated: November 17, 2026

Use of YouTube API Services

The "Pequenas Histórias Publisher" API client uses YouTube API Services. By using it, users agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who we are

Pequenas Histórias is a personal project by Fábio that publishes original historical short stories. The API client is a private, single-user tool used only by the author to publish his own videos to his own YouTube channel. It is not offered to the public and has no other users.

What data is accessed and how it is used

With the author's OAuth consent, the client accesses the author's own channel to upload videos, set thumbnails, read processing status and update metadata. It does not access data from any other user or channel (subscribers, comments, messages or viewer data). Data is used only to publish and check the author's own videos. It is never sold, shared for advertising or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage, sharing and deletion

The YouTube OAuth token is stored as an encrypted secret in the author's private GitHub repository and is used only by the publishing script. The client stores only the IDs and status of videos it uploaded to the author's channel. This website sets no cookies and collects no visitor data. Stored data can be deleted at any time on request through the contact below; when access is revoked, the token is deleted within 7 days. No other third party receives this data.

How to revoke access

Access can be revoked at any time via the Google security settings page.

Contact

Questions: direct message to @pequenas_historias_ai on Instagram.
